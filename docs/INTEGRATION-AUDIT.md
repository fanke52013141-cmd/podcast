## 二、本轮修复的 7 处断节

1. **文件上传是假的**：原只传文件名当素材 → 新增 `/api/upload` 落盘，返回路径进入抽取链（实测建任务成功）
2. **主题粘贴链接不抓正文**：原把 URL 当标题 → 服务端自动抓正文（本地 HTML 实测 61 字符提取成功）
3. **RSS 批量忽略界面配置**：原用 env 默认 → 风格/时长/音色/provider/BGM 全透传（实测批量任务 style=辩论/9min/指定音色）
4. **成本字段无消费**：tokens 记了但 UI 不显示 → 详情页 + 工作台"总成本"统计（DeepSeek 参考价估算）
5. **承诺 VTT 但不存在**：设置页写"SRT/VTT 双格式" → 管线生成 vtt + 详情页下载按钮
6. **模板只增不删**：工作台补删除入口（带确认）
7. **precise 时间轴未复用**：字幕精确但剪辑/音效仍用字数估算 → `bounds_from_srt` 反解精确边界，剪辑/音效/字幕共用一条时间轴（单测往返验证）

## 三、仍存在的限制（非隐藏断节）

### A. 等设备（功能位已留好）
- 句级重做按钮（需真 TTS 重合成）、双 ASR（Paraformer）、AudioSeal、SoundEffect、多引擎路由、音色工厂、CLAP、混响
- P1-13 参考音频特征缓存（需 SoulX 推理内部结构，P0 审计时做）

### B. 产品范围决定
- 仅支持双主播（契约/UI 固定 S1/S2；SoulX 可多人，扩展需动契约+UI）
- 通用列表页抓取只做 RSS（非 RSS 网页列表未支持）
- 术语读音表仅文件可改，无 UI（低频操作）
- VoiceStar 仅接口，无使用入口

### C. 技术债/小坑
- 夜间队列精确到分钟（服务恰在该分钟内启动可能错过当天，last_run 机制正确）
- 上传的参考音频不会自动转写 prompt_text（需人工填，P1-8 流程）
- 时间轴以 SRT 为单一真源，重合成后 _finalize 会重写 SRT 保持新鲜（已覆盖）
